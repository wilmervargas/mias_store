========================================================
  DAMASCO FULLSTACK - MES 6  (PROYECTO COMPLETO)
  Backend PHP 8 + Tienda React + Dashboard React
  Clases 1, 2, 3 y 4
========================================================

Este paquete contiene el proyecto Damasco terminado, tal como
queda al finalizar la Clase 4 del Mes 6:

  Clase 1 -> Lectura del catalogo con PDO + MVC + React.
  Clase 2 -> CRUD administrativo (productos, categorias, marcas).
  Clase 3 -> Subida de imagenes, filtros avanzados y reportes.
  Clase 4 -> Multimoneda, carrito persistente en MySQL,
             transacciones ACID y checkout de pedidos.

CONTENIDO
---------
  backend/       -> API REST en PHP 8 puro (patron MVC + PDO).
                    Incluye Producto, Categoria, Marca, Reporte,
                    Dolar, Carrito y Pedido.
  frontend/      -> Tienda publica en React + Vite + Tailwind.
                    Incluye carrito en MySQL, drawer, checkout,
                    recibo de pedido y precios en USD / Bs.
  dashboard/     -> Panel administrativo en React + Vite + Tailwind
                    (CRUD, subida de imagenes, reportes, clientes
                    y pedidos con detalle de cada orden).
  damasco.sql    -> Script completo de la base de datos.

  Las imagenes de los productos NO vienen dentro de este .rar.
  Descarga aparte  imgDamasco.rar  y descomprimelo en
  backend/imagenes/ (asi las fotos quedan en backend/imagenes/xxxx.png).

REQUISITOS
----------
  - WAMP Server (Apache + MySQL) encendido en verde.
  - PHP 8.1 o superior.
  - Node.js 18+ y npm.
  - WinRAR o 7-Zip para descomprimir las imagenes.

PASO 1 - BASE DE DATOS
----------------------
  1. Abre phpMyAdmin (http://localhost/phpmyadmin).
  2. Crea una base de datos llamada:  damasco
     (cotejamiento utf8mb4_general_ci).
  3. Importa el archivo  damasco.sql  dentro de esa base.
  4. Verifica que existan las tablas:
     productos, categorias, marcas, clientes, dolar,
     carritos, items_carrito, pedidos e items_pedido.

PASO 2 - BACKEND (PHP)
----------------------
  1. Copia la carpeta  backend/  dentro de la carpeta www de WAMP,
     por ejemplo:  C:\wamp64\www\damasco_api
  2. Descomprime  imgDamasco.rar  DENTRO de  backend/imagenes/.
  3. Abre una terminal en la carpeta  backend  y ejecuta:

        php -S localhost:8000

  4. Abre  http://localhost:8000/  en el navegador.
     Debe aparecer la landing de la API y decir "Conexion OK".

  NOTA: en  backend/config/Database.php  el usuario es  root  y la
  contrasena va vacia (lo normal en WAMP). Si tu MySQL usa el puerto
  3308, agrega  ;port=3308  al DSN.

PASO 3 - FRONTEND (Tienda publica)
----------------------------------
  Abre una terminal en la carpeta  frontend  y ejecuta:

        npm install
        npm run dev

  Se abrira en  http://localhost:5173  y consumira la API de
  http://localhost:8000.

  Flujo para probar la Clase 4:
  1. Agrega productos al carrito desde la tienda.
  2. Abre el drawer del carrito (boton 🛒 del navbar).
  3. Cambia la moneda entre USD y Bs.
  4. Pulsa "Proceder al Checkout".
  5. Elige un cliente de damasco.sql (por defecto Ana Perez, ID 1),
     completa la direccion y confirma el pedido.
  6. Verifica en phpMyAdmin:
     - Se creo una fila en pedidos.
     - Se crearon filas en items_pedido.
     - El stock de productos disminuyo.
     - El carrito quedo vacio (items_carrito).

  El carrito se guarda en MySQL (carritos / items_carrito) y usa
  localStorage solo como cache para arrancar sin conexion.

PASO 4 - DASHBOARD (Panel admin)
--------------------------------
  Abre OTRA terminal en la carpeta  dashboard  y ejecuta:

        npm install
        npm run dev

  Vite usara el siguiente puerto libre (por ejemplo 5174).

  Desde el Dashboard puedes crear, editar, desactivar y reactivar
  categorias, marcas y productos; subir imagenes; filtrar y ver
  reportes de inventario. Tambien incluye las pestanas de Clientes
  y Pedidos para consultar compradores y el detalle de cada orden.

ENDPOINTS PRINCIPALES DE LA API
-------------------------------
  PRODUCTOS Y CATALOGO
  GET    ?url=productos
  GET    ?url=productos/{id}
  GET    ?url=productos?q=texto&precioMin=50&precioMax=300&todos=1
  POST   ?url=productos                 (JSON)
  PUT    ?url=productos/{id}            (JSON, actualizacion parcial)
  DELETE ?url=productos/{id}            (borrado logico)
  POST   ?url=productos/{id}/imagen     (multipart/form-data)
  GET    ?url=categorias   /  ?url=categorias/{id}
  GET    ?url=marcas       /  ?url=marcas/{id}
  GET    ?url=reportes/resumen
  GET    ?url=reportes/stock-critico?umbral=10

  CLASE 4 - MULTIMONEDA, CARRITO Y PEDIDOS
  GET    ?url=dolar
  GET    ?url=carrito&cliente_id=1
  POST   ?url=carrito/items             { cliente_id, producto_id, cantidad }
  PUT    ?url=carrito/items/{id}        { cantidad }
  DELETE ?url=carrito/items/{id}
  DELETE ?url=carrito&cliente_id=1      (vaciar carrito)
  POST   ?url=pedidos                   { cliente_id, direccion_envio,
                                          metodo_pago, numero_referencia,
                                          tasa_dolar_usada }
  GET    ?url=pedidos                   (listado para el Dashboard)
  GET    ?url=pedidos&id={id}
  GET    ?url=clientes                  (listado para el Dashboard)

  Las respuestas incluyen las claves "success"/"datos" (usadas por
  la tienda y el dashboard) y "exito"/"mensaje"/"data" (usadas por
  los ejemplos de la Clase 4).
