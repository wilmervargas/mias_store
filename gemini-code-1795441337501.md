## 3. Base de Datos y Lógica de Autorización (Homóloga a `django.contrib.auth`)
1. **Login exclusivo por correo electrónico (`email`):**
   - No usar `username` para iniciar sesión.
   - Normalizar siempre el correo con `mb_strtolower(trim($email))` al crear, editar o autenticar.
   - Validar formato de correo, verificar que `is_active = 1` y comprobar la clave con `password_verify()`.
   - Responder siempre un mensaje genérico ante fallo (`"Correo electrónico o contraseña incorrectos."`) para evitar enumeración de usuarios.
   - Regenerar el ID de sesión (`session_regenerate_id(true)`) al iniciar sesión y actualizar `last_login`.
2. **Tablas en `mias_store` (consultas preparadas con PDO):**
   - `users`: `id`, `full_name`, `email` (UNIQUE), `password_hash`, `is_active` (TINYINT 1), `is_staff` (TINYINT 1), `is_superuser` (TINYINT 1), `last_login` (DATETIME NULL), `created_at`, `updated_at`.
   - `roles`: `id`, `name` (UNIQUE, ej. `ADMIN`, `OPERADOR`, `VENTAS`, `LECTOR`), `description`.
   - `permissions`: `id`, `code` (UNIQUE, formato `modulo.accion`, ej. `usuarios.ver`, `usuarios.crear`, `usuarios.editar`, `usuarios.eliminar`, `roles.gestionar`, `seguridad.claves`, más los permisos de los módulos existentes en `mias_store`), `module`, `description`.
   - `user_roles`: `user_id`, `role_id` (PK compuesta, `ON DELETE CASCADE`).
   - `role_permissions`: `role_id`, `permission_id` (PK compuesta, `ON DELETE CASCADE`).
   - `user_permissions`: `user_id`, `permission_id`, `allowed` (TINYINT 1: 1 = permitir, 0 = denegar explícitamente), PK compuesta.
3. **Regla de Superusuario (`Authz::can($permissionCode)`):**
   - Si el usuario no está autenticado o `is_active == 0` -> `false`.
   - Si `is_superuser == 1` -> **`true` inmediato** (acceso total sin necesidad de roles asignados, idéntico a Django).
   - Si existe override explícito en `user_permissions` -> retornar ese valor (`allowed == 1`).
   - Si algún rol asignado al usuario en `user_roles` tiene el permiso en `role_permissions` -> `true`.
   - De lo contrario -> `false`.
